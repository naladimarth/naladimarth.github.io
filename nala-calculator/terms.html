Accuracy, rounding and reliance on results

The calculator is a general-purpose tool. A result depends on the expression, inputs, units, mode and precision you select. Software defects, approximations and ambiguous inputs can produce an incorrect or unexpected result. A live preview reflects the expression as it currently stands, even when you have more to enter.

Stored and displayed values
Supported basic arithmetic can retain an exact value even when the screen shows a rounded one. Copying the displayed answer can give a different representation from copying the stored value. Scientific functions and some tools use approximations. Displaying more decimal places does not make an approximate result exact.
Angles, percentages and units
For example, the sine of 30 depends on whether the input is in degrees or radians. A percentage applied to an amount can differ from the same percentage entered on its own. US and Imperial units with the same name can have different sizes. Check the angle mode, operation and unit labels before reusing a result.
Graphs and tables
A graph plots sampled values within the visible range. Zoom, sampling and screen resolution can hide a narrow feature or make a curve appear continuous near a discontinuity. A crossing on the screen is an estimate. Check the function numerically or analytically before relying on a root, limit or trend.
