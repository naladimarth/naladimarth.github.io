Privacy Policy

This Privacy Policy explains how SIP Calculator: Net Worth, part of Nala Finance Calculator, handles locally stored financial information, application settings, and limited diagnostic information.

Application SIP Calculator: Net Worth
Developer Naladimarth
Effective date 17 July 2026
The application is an educational financial-calculation and personal net-worth tracking utility. It does not provide banking, brokerage, lending, investment-management, or personalised financial-advisory services.

1. Overview

Naladimarth respects user privacy and aims to collect only the limited technical information required to operate, maintain, secure, and improve the application.

Financial values entered into the application are intended to remain on the user's device. The application does not require an account, login, email address, phone number, or cloud profile.

2. Information stored locally

Depending on the features used, the application may store the following information locally on the user's Android device:

  • An optional display name
  • Selected currency and number-format preferences
  • Haptic-feedback and application settings
  • Saved SIP or recurring-investment calculation results
  • Asset and liability names and values
  • Net-worth totals and target amounts
  • Planner inputs, assumptions, and calculated estimates

This information is used to provide the application's features, restore preferences, display saved calculations, and maintain locally entered net-worth records.

Naladimarth does not operate a remote account database or cloud-sync service for this financial information.

Display names, financial inputs, asset or liability names, calculated results, and target amounts are not intentionally transmitted to Naladimarth, Firebase Crashlytics, advertisers, or unrelated third parties.

3. Device access and permissions

The application does not request access to contacts, precise location, camera, microphone, photos, files, SMS messages, call logs, or financial accounts.

Internet access may be used for diagnostic services, opening legal or support pages, and advertising functionality only when that functionality is enabled.

4. Firebase Crashlytics

Release versions of the application use Firebase Crashlytics, a service provided by Google, to identify crashes, application-not-responding events, and unexpected technical failures.

Depending on the failure and device environment, Crashlytics may process technical information such as:

  • Crash stack traces and technical error details
  • Application version and identifying app information
  • Android operating-system and SDK information
  • Device manufacturer and model
  • Network connection type
  • Relevant application state at the time of a failure
  • Crashlytics installation identifiers
  • Firebase installation identifiers
  • Application-session and foreground-session metrics
  • Developer-reported non-fatal technical errors

This information is used for application stability, troubleshooting, crash investigation, performance diagnosis, and reliability improvements.

Crash-report privacy controls

The application does not intentionally attach the following information to Crashlytics reports:

  • Display names
  • SIP or recurring-investment amounts
  • Asset and liability names or values
  • Net-worth values
  • Financial target amounts
  • Email addresses or phone numbers
  • Developer-defined user identifiers
  • Advertising identifiers

Developer-reported non-fatal errors are sanitised so that underlying exception messages that could contain stored financial information are not intentionally submitted.

Crashlytics collection is disabled for development debug and profile builds and enabled for release builds.

Firebase currently states that Crashlytics crash stack traces, associated identifiers, and related diagnostic information are retained for 90 days before the process of removing them from live and backup systems begins.

More information is available through Firebase Privacy and Security .

5. Supporting Firebase services

Firebase Crashlytics may use supporting Firebase components, including Firebase Installations and Firebase Sessions.

These components may process installation identifiers, application metadata, device metadata, operating-system information, and limited session information required to provide crash and quality metrics.

The current application does not use Firebase Authentication, Cloud Firestore, Firebase Realtime Database, Firebase Cloud Messaging, or Firebase Analytics.

6. Advertising and consent

The application includes technical support for future advertising, but advertising is disabled in the current version through a central application setting.

While advertising remains disabled, the application does not intentionally initialise the Mobile Ads service, create an ad object, request an advertisement, load an advertisement, display an advertisement, or show an advertising-consent form.

If advertising is enabled in a future version:

  • This Privacy Policy will be reviewed and updated before the ad-enabled version is released.
  • Advertising and consent functionality will be disclosed accurately in Google Play.
  • The Google User Messaging Platform may be used to request or manage privacy choices where required.
  • Advertisements will be requested only after the application determines that ads may be requested.

During development, only Google's official test-ad units are used. Test-ad units are not used to generate advertising revenue.

7. Data sharing and sale

Naladimarth does not sell locally entered financial information or personal information.

Limited diagnostic information may be processed by Google as the service provider for Firebase Crashlytics and its supporting Firebase components.

The application does not intentionally share locally entered financial records with advertisers, data brokers, lenders, banks, investment companies, or unrelated third parties.

8. Data security

Locally entered application information remains on the user's Android device and is protected by the security controls of the device and Android operating system.

Firebase states that applicable Firebase service data is encrypted in transit using HTTPS.

No electronic storage or transmission system can guarantee absolute security. Naladimarth limits remote processing to technical information required for application stability and approved future services.

9. Data retention

Local application information

Local information remains on the device until one of the following occurs:

  • The user deletes an individual saved record
  • The user uses the application's Reset App Data option
  • The user clears application storage in Android settings
  • The user uninstalls the application

The application does not provide its own cloud backup or cross-device synchronisation service.

Crashlytics diagnostic information

Crashlytics diagnostic information is retained according to Google's Firebase retention and deletion practices. Firebase currently states that applicable Crashlytics information is retained for 90 days before the removal process begins.

10. User controls and deletion

Users can remove locally stored information by:

  • Deleting individual saved records where available
  • Using Reset App Data inside the application
  • Clearing the application's storage through Android settings
  • Uninstalling the application

The application does not create a user account or attach an email address, phone number, or custom user identifier to Crashlytics reports.

Because anonymous diagnostic events are not connected to an account identity, Naladimarth may be unable to identify a specific Crashlytics report as belonging to an individual user.

Users may contact Naladimarth with privacy or deletion questions using the support address listed below.

11. Children's privacy

The application is a general financial utility intended for a general audience and is not designed or directed specifically toward children.

The application does not knowingly request names, contact information, account details, or financial-account credentials from children.

12. Financial information and estimates

Calculations and projections produced by the application are educational estimates based on the values and assumptions entered by the user.

Results are not guarantees of returns, investment performance, retirement outcomes, financial independence, affordability, or future value.

The application does not execute financial transactions, recommend specific investments, manage funds, connect to bank accounts, or replace professional financial, tax, legal, or investment advice.
